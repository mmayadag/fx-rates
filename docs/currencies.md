Operational notes:

- `EUR` is the base currency and is also stored in local coverage tables.
- The ECB page currently states that publication is usually updated around `16:00 CET` every working day.
- The ECB page also states that `EUR/RUB` publication is suspended until further notice; the last published `EUR/RUB` reference rate was on 1 March 2022.

If you want the current locally stored coverage instead of the ECB reference set, query your database directly:

```sql
SELECT iso_code, start_date, end_date
FROM currencies
ORDER BY iso_code;
```

Source links:

- ECB reference rates: https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html
- currencyapi currency list: https://currencyapi.com/docs/currency-list

To inspect ECB-specific coverage:

```sql
SELECT provider_key, iso_code, start_date, end_date
FROM currency_coverages
WHERE provider_key = 'ECB'
ORDER BY iso_code;
```
